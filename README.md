Данный проект является тестовым заданием для компании ITQ.

В данном проекте реализованы два микро-сервиса, взаимодействующие друг с другом через API.

Первый микро-сервис реализовывает функционал управления заказами и предоставляет REST API для клиента, в нем реализованы следующие функции:

1. Создание заказа
   
2. Получение заказа по его идентификатору

3. Получение заказа за заданную дату и больше заданной общей суммы заказа

4. Получение списка заказов, не содержащих заданный товар и поступивших в заданный временной период.
